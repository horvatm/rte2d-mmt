# RTE2D-MMT

RTE2D-MMT is a Python package under preparation for solving the
two-dimensional radiative transfer equation in plane-parallel layered media
using a mixed-precision modal-matching method.

## Project status

This repository is currently a placeholder. The package source code,
documentation, and supporting Jupyter notebook examples will be released here
after the associated paper has been accepted. No installable release is
available yet.

The planned examples will demonstrate calculations of spatially resolved
reflectance, transmittance, and fluence in layered media.
